Installing Convoy
====================

Convoy is a Mac app that brings your Claude desktop, Codex, and Antigravity sessions into one window,
and tracks each project's goals and progress on a project board.

Requirements
- macOS 14 (Sonoma) or later, Apple Silicon or Intel.
- At least one of: Claude desktop, the Codex desktop app, Antigravity — signed in and used at least once.

Install
1. Open Convoy-x.x.dmg and drag Convoy into the Applications folder. Run it from Applications, not from the disk image.
2. First launch: the app isn't notarized by Apple, so macOS says it can't verify the developer. Either:
   - In Applications, right-click (or Control-click) Convoy → Open → Open; or
   - If the dialog has no Open button (common on macOS 15+): double-click once so it's blocked, then go to
     System Settings → Privacy & Security, find "Convoy was blocked", click "Open Anyway" and enter your password; or
   - In Terminal run: xattr -dr com.apple.quarantine /Applications/Convoy.app  then open it normally.
3. A 5-step guide appears. Switch it to English on the first page (Chinese is the default). You can reopen it later from the home page.

Permissions
- Reading sessions needs no permission.
- Replying, answering questions, approving actions, and switching models need Accessibility:
  System Settings → Privacy & Security → Accessibility → turn on Convoy (click "+" and pick it from Applications if it's not listed).
- After an update, if messages stop sending, turn that switch off and on again.

Data and cost
- Everything stays on your Mac. Convoy has no server and uploads nothing.
- Project board summaries call the Claude Code CLI, Codex, or Antigravity on your Mac and use your own quota.
  Auto-update is off by default; check "Auto-update after each reply" on the board to start.
- "Share board with sessions" is off by default. Turning it on adds one hook to Claude Code (~/.claude/settings.json)
  and Codex (~/.codex/hooks.json), backing each file up before every change (as .agentdock-backup-<time>; the first one is .agentdock-backup); turning it off removes the hook.
- Convoy's own files: ~/Library/Application Support/AgentDock and ~/.agentdock

Uninstall
1. If you turned on "Share board with sessions", turn it off on the board first.
2. Quit Convoy (⌘Q) and drag it to the Trash.
3. To remove its data too, delete the two folders above.
